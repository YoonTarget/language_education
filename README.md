# 할머니 한글 - 영자 씨를 위한 한글 게임 앱

> 말은 할 수 있지만 글을 모르는 어르신을 위한 게임형 한글 문해 교육 앱

---

## 프로젝트 배경

북한에서 피난 오신 할머니(영자 씨)는 한국어로 의사소통은 완벽하게 되지만 한글을 읽고 쓰지 못하십니다.  
딱딱한 공부 방식은 싫어하시기 때문에, 게임처럼 즐기면서 자연스럽게 글을 익힐 수 있는 앱을 목표로 합니다.

**핵심 전제: 말소리는 이미 다 아신다. 그 소리에 글자 모양을 연결하는 것이 전부다.**

---

## 교육 이론적 근거

### 1. 성인 문해 교육 (Andragogy, Malcolm Knowles)
성인 학습자는 아이와 다른 방식으로 배웁니다.

| 원칙 | 앱 적용 |
|------|---------|
| 자기 주도성 | 원하는 시간에 짧게 학습, 강제성 없음 |
| 경험 기반 학습 | 할머니 일상에서 나오는 단어 우선 (약봉투, 버스, 마트 간판) |
| 즉각적 유용성 | "약국", "편의점", "출구" 등 당장 쓸 수 있는 단어부터 |
| 내재적 동기 | 레벨업·포인트보다 실생활 성취감 ("오늘 버스 번호 읽었어!") |

### 2. 음소 인식 + 한글 자모 체계 (Phonemic Awareness)
한글은 소리와 글자가 1:1로 대응하는 표음문자입니다.  
이미 소리 체계를 아는 분에게는 **기호→소리 연결**만 학습하면 되므로 성인 습득이 매우 빠릅니다.

```
소리(음소) 인식 → 자모 인식 → 음절 블록 결합 → 단어 인식
  (이미 완성)       (학습 1단계)    (학습 2단계)     (학습 3단계)
```

### 3. 음절 중심 접근법 (Syllable Block Method)
한글은 자음+모음이 모여 음절 블록을 이루는 구조입니다.  
`ㄱ + ㅏ = 가` 처럼 **블록 조합 원리**를 터득하면 처음 보는 글자도 읽을 수 있습니다.  
영어 파닉스와 유사하지만 훨씬 규칙적이라 성인도 수주 내 기초 습득 가능합니다.

### 4. 기능적 문해 교육 (Functional Literacy)
실생활에서 반드시 필요한 글자부터 배웁니다.  
UNESCO의 기능적 문해 정의: *"일상생활의 기능을 수행하는 데 필요한 읽기·쓰기 능력"*

우선순위 단어군:
- 장소 표지판 (약국, 병원, 화장실, 출구, 지하철)
- 음식·상품 (쌀, 물, 우유, 약)
- 가족 이름·호칭
- 전화·메시지 (전화, 문자, 확인)

### 5. 전체 언어 접근법 (Whole Language Approach)
글자를 낱낱이 외우기보다 **의미 있는 맥락** 안에서 배웁니다.  
사진(마트 간판 사진) → 소리("약국") → 글자("약국") 순으로 연결합니다.

### 6. 간격 반복 학습 (Spaced Repetition)
한 번 배운 글자를 점점 늘어나는 간격(1일 → 3일 → 7일)으로 복습시켜  
장기 기억에 정착시킵니다.

## 학습 커리큘럼 (5단계)

```
1단계  기본 모음 10개        ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ
         ↓
2단계  기본 자음 14개 + 단모음    가나다라마바사아자차카타파하
         ↓
3단계  받침 없는 두 글자 단어    고모, 사과, 버스, 나무
         ↓
4단계  받침 있는 글자            밥, 집, 문, 약, 물
         ↓
5단계  실생활 문장              "약국은 몇 시에 열어요?"
```

각 단계마다 새 글자를 배우기 전 **소리 듣기 → 연결 게임 → 확인 퀴즈** 순서를 반복합니다.

## 게임 모드 설계

### 🎵 모드 1: 소리 찾기 (Sound Matching)
- 앱이 소리를 들려주면 (`"가"`) 화면에 보기 4개 중 맞는 글자를 탭
- 아는 소리에 글자 모양을 연결하는 첫 번째 훈련
- 오답 시 정답을 크게 보여주고 다시 소리 재생

### 🧩 모드 2: 글자 조립 (Syllable Builder)
- 자음 블록과 모음 블록을 드래그해서 음절을 완성
- `ㄱ` 블록 + `ㅏ` 블록 → `가` 완성 → 소리 재생
- 한글의 조합 원리를 직접 체험

### 🃏 모드 3: 짝 맞추기 (Memory Cards)
- 그림 카드와 글자 카드를 뒤집어서 짝 맞추기
- 예: 🍎 사진 카드 ↔ `사과` 글자 카드
- 익숙한 단어로 시각적 기억 강화

### 🏪 모드 4: 간판 읽기 (Sign Reader)
- 실제 생활 속 간판·표지판 사진을 보여주고 읽게 유도
- 약국, 편의점, 지하철역 등 할머니 일상 동선 기준
- "오늘 이 간판 읽을 수 있어요!" 성취 메시지

### ✍️ 모드 5: 따라 쓰기 (Tracing)
- 화면에 글자 획순 가이드가 표시되고 손가락으로 따라 그리기
- 쓰기 훈련 (선택적 - 쓰기보다 읽기 우선)

### 🎤 모드 6: 받아쓰기 퀴즈 (Dictation Quiz)
- 소리를 듣고 해당 음절 버튼들을 순서대로 탭해서 단어 완성
- 예: `"사과"` 소리 → `사` 탭 → `과` 탭 → 정답!

## UI/UX 설계 원칙 (어르신 친화)

- **글자 크기**: 최소 24pt 이상, 버튼은 손가락 2마디 크기 이상
- **색 대비**: 고대비 색상 (흰 배경 + 진한 글씨)
- **터치 영역**: 오탭 방지를 위해 버튼 간격 넉넉하게
- **소리 우선**: 모든 글자·단어·문장은 탭하면 즉시 소리 재생
- **진행 시각화**: 복잡한 그래프 대신 꽃이 피는 등 직관적 시각화
- **짧은 세션**: 1회 학습 5~10분 권장, 자동 저장
- **오류 친화**: 틀려도 "아쉬워요! 다시 들어볼까요?" 같은 따뜻한 피드백
- **한국어 UI 전용**: 영어 없이 완전 한국어 인터페이스

## 기술 스택 (제안)

| 항목 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | React Native + Expo | iOS/Android 동시 지원, 빠른 빌드 |
| TTS | expo-speech / React Native TTS | 글자 탭 시 소리 재생 |
| 로컬 저장 | AsyncStorage / SQLite | 인터넷 없이도 학습 진행 저장 |
| 간격 반복 | 자체 구현 or ts-fsrs | 복습 스케줄 관리 |
| 애니메이션 | React Native Reanimated | 글자 조립 드래그 애니메이션 |

> **오프라인 우선 설계**: 할머니가 와이파이 없는 환경에서도 학습 가능해야 함

## 개발 우선순위 (MVP)

```
Phase 1  핵심 게임 2개 (소리 찾기 + 짝 맞추기) + 1~2단계 커리큘럼
Phase 2  글자 조립 게임 + 3~4단계 커리큘럼
Phase 3  간판 읽기 + 5단계 + 간격 반복 복습 시스템
Phase 4  따라 쓰기 + 통계/성취 시스템
```

## 폴더 구조 (예정)

```
src/
  curriculum/     # 학습 데이터 (자모, 단어, 문장 JSON)
  games/          # 각 게임 모드 컴포넌트
  hooks/          # 학습 진행 상태, 간격 반복 로직
  screens/        # 홈, 스테이지 선택, 게임 화면
  assets/         # 이미지(간판 사진 등), 오디오
  utils/          # TTS 래퍼, 진행도 저장
```
